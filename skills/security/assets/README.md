# Security assets

Reusable, portable templates:

- [Security Evidence](security-evidence.template.md) — candidate identity, scope, checks, findings, acceptances, uncertainty and final gate.
- [Risk Acceptance](risk-acceptance.template.md) — explicit human authorization record for a residual risk.

Templates are starting points, not permission to fabricate evidence. Do not place secrets, customer data, or author-machine private state in completed records.
